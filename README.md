## v14.32

IBD 자료를 입력하거나 그대로 보여주는 분석은 앱에서 뺐습니다. Pulse, Checkup, 북 시드는 화면에 나오지 않습니다.

- 나스닥 종합과 S&P 500 일봉으로 분산일을 계산합니다. 조건은 종가 -0.2% 이하, 거래량이 전일보다 많음, 최근 25거래일, 이후 종가가 그날 종가의 +5%를 넘으면 만료입니다.
- 세션마다 `data/dd_ledger.json`에 개수와 날짜를 저장하고, 다음 실행에서 같은 봉으로 다시 세어 일치·불일치를 표시합니다.
- 시장 점수는 이평과 분산 감점 뒤에도 상한이 있습니다. 분산 5개면 28, 6개면 18을 넘기지 않습니다. 두 지수가 함께 나쁘면 시장 점수 상한을 더 내립니다. 적극 매수 문구는 두 지수 분산이 각 1개 이하이고 오늘 분산이 없으며 둘 다 50·200일선 위일 때만 열립니다.
