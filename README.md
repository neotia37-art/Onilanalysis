# CANSLIM TERMINAL v13.0

일지([빨방홀러 4화](https://bbabangholer.tistory.com/16))와 보유 판단에서 드러난 규칙 구멍을 닫은 버전입니다.

## 배포

`app.py`만 올리면 Streamlit Cloud가 `main`을 다시 빌드합니다.
`.streamlit/config.toml`, `requirements.txt`는 그대로입니다.

## v13에서 고친 것

- **8주 보유 규칙** — 예전에는 `3주 내 +20%`와 `경과일 ≤ 21일`을 AND로 묶어, 3주가 지나면 규칙이 꺼졌습니다. 이제 3주 내 +20%가 한 번 성립하면 **돌파 +56일까지 유지**하고, 만료 뒤에만 일반 익절로 전환합니다.
- **돌파일 탐색** — 최근 20거래일만 보던 버그를 고쳤습니다. 베이스 저점 이후 **첫 피봇 종가 돌파**를 찾습니다.
- **돌파 행 가격** — “돌파 완성” 칸에 현재가를 넣던 표시를 고치고, 돌파 당일 종가 + 거래량 배수를 넣습니다.
- **가짜돌파** — 돌파 거래량 1.4배 미만이면 결함 + 상단바 `가짜돌파 위험`. 매수 구간이어도 보류(warn).
- **핸들 없는 돌파** — 기본값을 가짜돌파 쪽으로 두고 체크리스트에 핸들 항목을 추가.
- **C 25% 엄격** — +20~25%는 “거의 됐다”가 아니라 미달 경고.
- **+15% 준비 구간** — my투자에서 매수가 대비 +15~20%면 “오늘 20% 계획을 적는다”.
- **피벗 전 진입** — 매수가가 피봇보다 낮으면 예외로 표시.
- **상단바** — 시장 90점이어도 종목이 연장이면 `추격 매수 금지`가 같이 뜨니다.
- **컨센 목표가·실적 일정** — yfinance에서 평균/고/저 목표가, 투자의견, forward EPS, next earnings, earnings_dates를 자동 수집해 분석보강 STREET에 표시.
- **일지 종목 불러오기** — my투자에서 WT·NTAP·HNGE 시드를 넣을 수 있습니다. 이후 시세·전략은 자동 갱신.

## 자동으로 갱신되는 숫자

시세, 피봇/이평, RS, 거래량 배수, 8주 규칙, 매도압력, CANSLIM 점수,
yfinance 컨센 목표가·선행PER·기관보유%, 다음 실적일(있을 때).

## 자동이 안 되는 숫자 (직접 확인)

- 자산운용사 **AUM·순유입·fee rate** (월간 공시)
- GAAP vs Adjusted EPS 분리
- 국내 수급(Streamlit Cloud에서 KRX 차단될 수 있음)
- 증권사 리포트 목표가 변경 직후(yfinance 반영 지연)

방법: 분석보강 STREET가 비면 해당 종목 IR / 월간 AUM 보도자료를 메모에 남기고,
my투자 메모 칸에 방어선 숫자를 적어둡니다.
